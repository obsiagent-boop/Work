# Cream & Ivory Theme Reference for qnt. Monographs

## CSS Token Definitions
- **Page Background:** `#FAF8F5` (Warm Cream / Ivory Canvas)
- **Accent Background (Header/Access Boxes):** `#F4EFEA` (Soft Sand)
- **Card Background:** `#FFFFFF` (Crisp Warm White)
- **Primary Text:** `#000000` / `#0A0A0A` (Pitch Black)
- **Secondary Text:** `#1E293B` / `#334155` (Deep Slate)
- **Border Lines:** `1.5px solid #000000` (Obsidian Rule)
- **Table Headers:** `background-color: #000000; color: #FFFFFF; font-weight: 800;`
- **Table Row Dividers:** `0.5px solid #CBD5E1;`
- **Brand Title:** `qnt.` rendered in bold black typography (`font-size: 28pt; font-weight: 900; letter-spacing: -1.5px;`).

## Layout Principles
- Never use colored backgrounds that reduce readability.
- Maintain maximum contrast with deep black font on light cream background.
- Embed official URLs in clear, readable underlined links.
