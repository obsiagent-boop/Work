# Continuous Dense Text & Structural Table Parsing Standards for qnt. Research Intelligence

## Core Rules for Research Dossiers (e.g. Project "Skills", AI Subscriptions, Server Infrastructure)

1. **Continuous Editorial Text Flow (No Forced Block Tables for Everything):**
   - Research intelligence must NOT be confined strictly to artificial, rigid grid cards or tables.
   - Parse research primarily into dense, well-structured, multi-paragraph technical prose with clear bold headings.
   - Use structural tables ONLY for concise summary metadata (e.g. Pricing, Official Portals, Resource Scopes, Payment Compatibility).

2. **Absolute Elimination of Empty Page Bottoms / Spacing Voids:**
   - Never use `page-break-after: always;` inside repeating entry loops.
   - Remove oversized `break-inside: avoid;` on whole-page containers.
   - Apply `break-inside: avoid;` ONLY to small UI elements (tables under 120px, code snippets, callout boxes).
   - Use `break-after: avoid;` on section and module headers so headings never orphan at page bottoms.
   - Ensure content flows continuously from top header to bottom footer across all 50+ pages.

3. **Luxury Cream & Black Institutional Palette (`DESIGN.md`):**
   - Canvas Background: `#FAF8F5` (Warm Ivory / Luxury Cream).
   - Card / Panel Fills: `#FFFFFF` with `1.5px solid #000000` solid borders.
   - Typography: 100% Pure Pitch-Black (`#000000`) using Inter Variable (`file:///data/fonts/InterVariable.ttf`) with compact line-height (`1.28–1.30`).
   - Callouts: `#F4EFEA` soft sand background with `3.5px solid #000000` left accent bar.

4. **Pure Technology & Operations Focus (No Compounding Clutter):**
   - In research projects conducted by **`qnt.` Research Intelligence** (e.g., project `skills`, AI models, server hardware), exclude internal wealth-compounding tables (₹1k/₹10k/₹1L compounding) and financial advisory safe harbors unless explicitly requested. Focus 100% on technical specifications, step-by-step lab sandboxes, verified download links, and actionable career/monetization roadmaps.
