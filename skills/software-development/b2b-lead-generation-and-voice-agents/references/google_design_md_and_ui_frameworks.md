# Google DESIGN.md Token Specification & UI Framework Integration

## Core Architecture
This reference codifies Google's official `DESIGN.md` specification and maps it to modern production UI component registries.

## Token Specifications (Cyber Void & Sovereign Cream)
- **Void Canvas:** `#060811` (Deep background), `#0F1527` (Glass surface card)
- **Cyan Glow Accents:** `#06B6D4` (Primary button & glow), `#22D3EE` (Bright text accent)
- **Luxury Cream Canvas:** `#FAF8F5` (Monograph background), `#F4EFEA` (Card surface)
- **Fincept Factor Accents:** Equities (`#EA580C`), Theta Cashflow (`#2563EB`), Sovereign Fixed (`#059669`), REITs (`#9333EA`), Gold (`#D97706`), US Tech (`#06B6D4`)
- **Typography:** `Inter Variable` (UI Body & Headers), `JetBrains Mono` (Tickers & Formulas)

## Integrated UI Frameworks & Registries
1. **ui.aceternity.com:** Bento Grids, Background Beams, Glow Meshes, 3D Pin Cards.
2. **reactbits.dev:** Animated counters, interactive stat selectors, number streamers.
3. **componentry.dev:** Accessible animated tab matrices, modals, popovers.
4. **toggle.supply:** Tactile micro-interaction switches and sliders.
5. **motion.dev:** Layout transition physics and scroll-driven animations.
6. **styles.refero.design:** High-density Midnight & Abyssal production layout benchmarks.
7. **getdesign.md / designmd.cc:** Live measured DOM tokens, computed styles, and breakpoint grids.

## Operational Workflow Rule
Always state the design plan, color tokens, layout hierarchy, and reference sources for user review before generating or editing UI code.
